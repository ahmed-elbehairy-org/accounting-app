# Project Rules

1. **Max File Length**: No file may exceed 100 lines of code. Break down large components, subviews, hooks, and utilities into small, focused modules.
2. **Clean & Refactored**: Write simple, clean, and refactored code.
3. **TypeScript Only**: Always choose TypeScript (`.ts`, `.tsx`) over JavaScript.
4. **Initial State**: Empty state by default; no hardcoded demo or mock entities.
